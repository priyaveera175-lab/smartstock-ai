# smart_stock_ai_demo Flow

This project defines a declarative CrewAI Flow in `src/smart_stock_ai_demo/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/smart_stock_ai_demo/flow.yaml` to change the flow. Add reusable crews under `src/smart_stock_ai_demo/crews/`, custom Python tools under `src/smart_stock_ai_demo/tools/`, and shared knowledge files under `src/smart_stock_ai_demo/knowledge/`.
